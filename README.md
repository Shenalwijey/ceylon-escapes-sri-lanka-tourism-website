# ceylon-escapes-sri-lanka-tourism-website

# 🌴 Ceylon Escapes — Sri Lanka Tourism Website

A fully responsive, multi-page **frontend** website for a Sri Lanka tour company — Ceylon Escapes.

> 🚧 **Frontend only** — Backend (auth, bookings, payments) is planned as a future improvement.

---

## 🔗 Live Demo

👉 [View Live Site](https://shenalwijey.github.io/ceylon-escapes-sri-lanka-tourism-website/)

---

## ✨ Features

- 🏠 Multi-page layout — Home, About, Destinations, Packages, Booking, Contact, Login
- 📱 Fully responsive design
- 🎨 Dark elegant theme with gold accents
- 🗺️ Destinations section with location cards
- 📦 Tour packages with pricing
- 📅 Booking form with package & date selection
- 📬 Contact page with office details
- 🔐 Login page with Google & Facebook OAuth UI
- 💬 WhatsApp live chat widget UI
- 💱 Currency switcher component

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript

---

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/ceylon-escapes-frontend.git
cd ceylon-escapes-frontend
# Open index.html in your browser or use VS Code Live Server
```
